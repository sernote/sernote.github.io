## Expand / improve / no-expand / stop decision

Evaluate against the fixed expand thresholds. **Expand only when at least two of the
three signal classes are met:**

- **3** independent applications, **and/or**
- **2** qualified inbound requests that each name a specific artifact, **and/or**
- **2** organic citations or recommendations.

| Review date | Applications | Inbound requests | Citations/recommendations | Signal classes met (need ≥2) | Decision |
| --- | --- | --- | --- | --- | --- |
| | | | | | expand / improve / no-expand / stop |

- **expand** — thresholds met; add at most two reviewed materials or one next vertical.
- **improve** — demand is forming; sharpen existing artifacts, do not expand scope.
- **no-expand** — insufficient signal; hold the pilot as-is and keep observing.
- **stop** — no meaningful signal after the full pilot window; retire or archive.

Do not substitute page views, impressions, or social metrics for these outcome signals.
