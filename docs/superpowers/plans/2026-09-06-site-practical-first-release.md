# Практические входы и редакционные исправления — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Устранить точные несостыковки публичной подачи, закончить один практический путь и помочь находить готовые материалы.

**Architecture:** Существующие статические MDX и шаблоны v3.1. Сохраняем текущую типографику, четыре пункта меню, адреса, первичные источники и структуру reference-данных. Каждый из трёх этапов самостоятельно проверяется и сохраняется отдельным коммитом.

**Tech Stack:** Next.js App Router, TypeScript, Fumadocs MDX, Tailwind, pnpm; статический экспорт.

## Авторизация и границы

План исполняет обсуждённые выпуски A/B/C из `.agent/SITE_PLAN_REVIEW_2026-09-06.md` с итогом консилиума. Пользователь после чтения итогов ответил «Ну ок, давай править». Нового согласования обратимых исправлений не требуется. Это узкое дополнение к нормативной v3.1-спецификации: оно заменяет требования к служебным подписям, буквальным заголовкам области, месту оглавления reference и составу подборок, только в указанных пределах.

Не входят: новые статьи и разделы, RSS-модель, поиск, переводы, новый калькулятор или роутер, смена визуального стиля. Публикация и merge не выполняются автоматически. Исходный checkout с пользовательским черновиком не изменяется.

## Проверка

Команды выполняются в `/private/tmp/notevskii-site-editorial-fix` через `PATH=/private/tmp/notevskii-site-pr-bin:$PATH corepack pnpm …`.

Редакторские изменения проверяются чтением и браузером, без новых тестов на дословное совпадение всей статьи. Тесты нужны для фактической роли участника, работы оглавления и сохранения навигационных контрактов. Существующие проверки метаданных и структуры корректируются вместе с данными. После исправлений проходят lint, typecheck и build; перед завершением — общий `verify`.

Готово: подписи соответствуют действию; первая проверка доступна; у читателя есть путь и для чтения, и для возвращения к разделу; нет повреждённых старых якорей или новых публичных описаний процесса подготовки. Дальнейшая полировка кэша не является условием следующего материала.
