## Редакционные границы

- Не пересказываем видео по памяти и не добавляем неподтверждённые детали.
- Пользовательские таймкоды сохраняем как точки входа. Дополнительные таймкоды не вычисляем приблизительно.
- `takeaways` используют один подтверждённый таймкод на материал; остальные выводы остаются без timestamp.
- Страницы не дублируют длинные тексты существующих материалов и не содержат технического блока «проверенный снимок».
- Оба материала связываются с существующими докладами о выборе моделей. Новых компонентов AI Platform и нового интерфейса не добавляем.

## Поведение сайта

- В «Материалах» появляются две строки в хронологическом порядке по дате события.
- У каждого материала есть локальная canonical-страница, локальная обложка и `VideoObject`.
- Главная не меняется: более свежий подкаст остаётся текущим материалом.
- RSS не меняется, потому что действующая лента содержит статьи, а не выступления.
- В route manifest и sitemap добавляются два `keep`-маршрута.

## Проверка

TDD фиксирует метаданные, предоставленные таймкоды, порядок в «Материалах», маршруты, sitemap, JSON-LD и статический экспорт. После реализации проходят `pnpm verify`, `git diff --check`, проверка экспортированного HTML и live-smoke после GitHub Pages.
