## Проблема

Serving модели - не то же самое, что operating inference как platform capability.

## Симптомы

- Throughput хорош в benchmark, но TTFT плохой в продукте.
- GPU utilization высокий, но successful task cost хуже, чем MaaS.
- Новые модели запускаются копированием flags из chat history.

## Ментальная модель

Inference runtime - это продукт model, hardware, scheduler, batching, memory, cache, routing и workload shape.

## Архитектура

Runtime layer включает OpenAI-compatible serving, model workers, batching, KV-cache, prefix cache, quantization, speculative decoding, multi-GPU serving, autoscaling, capacity planning и non-LLM models: STT, embeddings, rerankers.

## Метрики

Отслеживай TTFT, TPOT, total latency, tokens per second, queue time, batch size, cache hit rate, GPU memory, utilization, error rate, cold starts и cost per accepted outcome.

## Компромиссы

Более высокий throughput может увеличить latency. Quantization снижает memory и cost, но может ухудшить quality. Больший context уменьшает truncation, но увеличивает prefill и cache pressure.

## Анти-паттерны

- Считать vLLM flags фольклором вместо versioned recipes.
- Выбирать hardware по brand debates, а не workload envelope.
- Serving LLMs и игнорировать embeddings, STT и rerankers как platform citizens.
